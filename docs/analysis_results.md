## 9. Is a bounce predictable from ticket fields? (decides whether v0 uses ML)

Time-split logistic regression (train first 70% of escalations, test last 30%, n_test=146): ticket fields AUC=0.48, ticket fields + agent AUC=0.52. AUC ~0.5 = no better than chance. Bounces depend on what is *in* the escalation, which the data does not record. So v0 uses transparent rules + checklists, not a predictive model.

## 10. Backtest: would 'related engineering tickets' have surfaced known issues?

For each historical escalation, using only tickets created before it (no look-ahead): related ticket shown for 77.2% of escalations; 78.6% of eventual 'Duplicate of known issue' escalations would have had a related ticket shown; only 11.7% of shown cases were duplicates (base rate 11.5%). Precision equals the base rate (also tested: 7/14/30-day windows, similarity 0.35/0.6/0.9, open-only), because the same templated descriptions recur constantly. Conclusion: text similarity cannot identify known issues in this data. v0 shows recent similar escalations as context and never blocks; a real known-issue registry needs engineering to tag incidents (roadmap week 3).
